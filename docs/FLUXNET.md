# FLUXNET

FLUXNET is a global network of micrometeorological tower sites that use eddy covariance methods to measure the exchanges of carbon dioxide, water vapor, and energy between the biosphere and atmosphere.
See, [more details](https://fluxnet.org/)

## Access FLUXNET data

We use Shuttle Library, a Python library for FLUXNET shuttle to discover and download global FLUXNET data from multiple data hubs, including Ameriflux, ICOS, and TERN.
For more information : https://github.com/fluxnet/shuttle/blob/main/README.md
